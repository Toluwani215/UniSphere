#UniSphere - System Design 

## 1. System Overview 
UniSphere is a web-based platform that provides university students with easy access to important academic information.

## 2. Main Components

### Student Interface 
Allows students to view course information, announcements and academic updates.

### Admin Interface 
Allows authorised users to manage academic information and announcements

### Course management
Organise information according to individual courses and departments

### Database
Stores student information, course details and announcements. 

## 3. User Roles 

-Students: View academic information

Class Representatives: Share relevant course updates

Lecturers: Provide academic announcements 

Administrators: Manage the platform 

## 4. Information Flow 

1. Authorised users submit academic information.
2. The system receives and processes the information.
3. Information is organised according to courses.
4. Students access the relevant information through the platform.

## 5. Platform Requirements 

-A simple and user-friendly interface.
-Secure access for authorised users.
-Organised course information.
-Reliable information storage.
-Accessibility across different devices.

## 6. Future Improvements 

-Student notification
-Search functionality
-Timetable Management 
-Assingment and deadline reminders
