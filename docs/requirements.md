#UniSphere - Project Requirements

## 1. Introduction 
UniSphere is a student-focused platform designed to help university students access important academic information in one place.

## 2. Purpose 
The purpose of UniSphere is to make academic information easier to access, organise and manage.

## 3. Functional Requirements 
-Students should be able to access important course information.

-Students should be able to view academic announcements.

-Information should be organised according to individual courses.

-Class representatives and lecturers should be able to share relevant updates. 

## 4. Non-Functional Requirements 
-The platform should be easy to use

-Information should be organised clearly.

-The platform should protect users' information

-The platform should be accessible on different devices 

## 5. Target Users 
-University students

-Class representatives

-Lecturers 

## 6. Expected Outcome 
UniSphere should provide a central platform where students can easily find important academic information without searching through multiple WhatsApp groups
